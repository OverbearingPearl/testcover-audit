# pearl-testcover

Pearl Testcover is an Emacs Lisp package that adds quantitative coverage statistics to Emacs' built-in testcover.el. Instead of just highlighting uncovered forms with colored markers, it shows you the coverage percentage, counts of covered, uncovered, and 1value forms, and can generate per-function breakdowns. If you've ever wondered "how much of my code is actually tested?", pearl-testcover gives you the answer in numbers.
